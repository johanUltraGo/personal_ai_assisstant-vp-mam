Vice Principal AI — Setup Checklist

Project folder: C:\personal-ai-assisstant  ·  Full details: server\README.md  ·  Steps 1–2 ≈ 15 min, step 3 ≈ 20 min

1. Create the settings file

  • Open PowerShell and open the settings file (it already exists — do not copy .env.example over it):
cd C:\personal-ai-assisstant\server
notepad .env
  • APP_ACCESS_PIN= a PIN of 6+ digits (only you and Uma know it)
  • SCHOOL_NAME= the school's name
  • VAPID_SUBJECT= change to mailto: + your email

Already filled in for you: TOKEN_ENCRYPTION_KEY, VAPID_PUBLIC_KEY, VAPID_PRIVATE_KEY — leave them as they are.

2. Claude key — turns on the assistant

  • Go to console.anthropic.com → sign in → add billing
  • API Keys → Create Key
  • Paste it into .env as ANTHROPIC_API_KEY=

3. Gmail and Drive — Google Cloud (≈ 20 min)

  • Go to console.cloud.google.com → create a project (e.g. "VP Assistant")
  • APIs & Services → Library → enable Gmail API and Google Drive API
  • OAuth consent screen: Internal if the school email is Google Workspace; otherwise External + add Uma's email as a test user (External = she signs in again every 7 days)
  • Credentials → Create credentials → OAuth client ID → Web application
  • Add this redirect URI exactly:
http://localhost:4000/api/google/oauth/callback
  • Copy the client ID and secret into GOOGLE_OAUTH_CLIENT_ID= and GOOGLE_OAUTH_CLIENT_SECRET=

4. Load the new settings

The app already runs in the background (it starts with Windows). After editing .env, restart it:

npm.cmd run service:restart
  • Open http://localhost:4000 and enter the PIN

Use npm.cmd: a stray empty file C:\Windows\System32\npm hides the normal npm in PowerShell.

5. Set it up on the page

  • Connections → Connect Google account → sign in with the school account (and her personal one if needed)
  • Messages → Contacts and groups → add "Parents group", "Teachers group" and key staff
  • School calendar → paste the Drive link of the calendar file, or upload it
  • Talk to your assistant → try: "Remind me in 5 minutes to check the attendance"

6. Tell Claude it's running

  • Ask for a live check of the assistant, sending an email, reading a Drive file and the calendar

Later — before Uma uses it on her phone

  • Hosting: an always-on computer or server with an https address (notifications need https)
  • On her phone: open the https address in Chrome → menu → Install app (icon on her home screen)
  • Then in the app → Connections → Turn on notifications on this phone
  • Uma tests each feature (the spec requires it before each phase is signed off)
